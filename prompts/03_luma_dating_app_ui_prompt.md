# DATING APP UI PROMPT — Luma

Generate an image of a complete modern mobile app UI design system and all screen designs for a dating app called "Luma".
Luma is a premium, modern dating app designed to help people form genuine romantic connections through thoughtful profiles, beautiful discovery flows, personality-based matching, and warm conversation design.

## Design Style & Color Palette
- Ultra modern 2026 startup aesthetic, light mode first (`#FFFFFF` / `#FBF7F4`)
- Primary accent: warm rose-coral (`#FF5F7E`), Secondary accent: soft lavender (`#8E7CFF`)
- Soft rounded corners (18–24px radius), subtle drop shadows, pill-shaped tags and metadata pills ("2 km away", "92% match", "Active now")
