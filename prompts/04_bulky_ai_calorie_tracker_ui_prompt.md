# CALORIE TRACKER APP UI PROMPT — Bulky AI

Generate a complete modern mobile app UI design system and screen designs for a fitness mobile app called "Bulky AI" designed for skinny people who want to gain weight and build muscle.

## Design Style & Color Palette
- Ultra modern 2026 startup aesthetic, dark mode first (`#0F1115` charcoal backgrounds)
- Soft whites, electric blue accents, subtle cyan gradients, rounded corners, smooth charts
