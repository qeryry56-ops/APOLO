# DENTAL APP UI PROMPT — DentaCare

Create an ultra-high-resolution UI showcase board for a premium dental-care mobile app called "DentaCare" — a modern digital dentistry platform for finding dentists, booking appointments, video consultations, dental records, and treatment tracking.

## Design Style & Color Palette
- Ultra-modern 2026 healthcare startup aesthetic, light mode with luminous icy-blue backgrounds (`#FFFFFF`, `#F7FBFF`, `#EAF6FF`)
- Deep dental blue (`#075A92`), aqua primary (`#24D4DF`), turquoise (`#26C6DA`), cyan glow (`#8AF5FF`), navy text (`#17324A`)
- Translucent glassmorphism cards, rounded corners (18–28px), glossy 3D dental visual assets
