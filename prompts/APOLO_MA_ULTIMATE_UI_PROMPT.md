# APOLO.MA — ULTRA-MODERN 2026 MARKETPLACE & PRO STORES APP UI PROMPT

Generate an ultra-high-resolution UI showcase board of a complete modern mobile app UI design system and all screen designs for Morocco's next-generation classifieds and Pro Stores marketplace app called **"Apolo.ma"**.

## Design Style
- Ultra modern 2026 startup aesthetic (Apple-level clean UI mixed with luxury editorial commerce branding)
- Light mode first with airy off-white backgrounds (`#FFFFFF` / `#F8FAFC`)
- Large immersive product photography as the hero of every card and detail screen
- Soft rounded corners (`18px–24px` radius), subtle multi-layered depth, floating cards, and translucent glassmorphism badges
- Pill-shaped buttons, category filter chips, and metadata pills (`"VIP"`, `"كازابلانكا"`, `"جديد"`, `"قابل للتفاوض"`)
- Bilingual support: Arabic RTL (`Tajawal` / `Cairo` style) and French LTR (`Inter` / `SF Pro` style)

## Color Palette
- Crisp white & airy slate backgrounds (`#FFFFFF` / `#F8FAFC`)
- Royal Ocean Blue primary accent (`#1E56A0` -> `#2563EB`)
- Sunset Coral-Orange secondary CTA (`#FF6B00`)
- Luxury Amber Gold for VIP & Boosted listings (`#F59E0B`)
- Emerald Green for verified stores & WhatsApp actions (`#10B981`)
